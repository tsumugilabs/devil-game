# DEVIL GAME

自動で進む小さな悪魔をジャンプさせ、初見殺しの罠を突破する全11ステージのブラウザーゲーム。

## 遊び方

- Space / ↑ / 画面タップ：ジャンプ
- 短押し：低く跳ぶ。長押し：高く跳ぶ
- R：現在のステージから再挑戦
- クリアすると次のステージへ。死亡回数はページを開いている間の累計です。

開閉・加速する穴、移動・出直しするトゲ、落下する天井、偽ゴール、ジャンプを誘う狭い通路を配置しています。7面では狭い通路を跳ばずに進み、天井を抜けたゴール直前の本物の穴だけはジャンプで越えます。8面では誘導罠と本物の罠を組み合わせています。9・10面のゴールは約0.3秒で逃げて足元に穴を開け、10面では着地後の再ジャンプが必要です。11面は最初の穴から入る地下道だけが正解で、最後は短押しジャンプで突破します。罠は固定配置で、すべてのステージに突破可能なルートがあります。

## 起動

`dist/index.html` をブラウザーで開くだけで動きます。ビルド、依存パッケージ、通信は不要です。

公開先：https://tsumugilabs.github.io/devil-game/

main の dist 更新で GitHub Actions が自動公開します。

## 構成

- `dist/index.html`：画面
- `dist/style.css`：レスポンシブスタイル
- `dist/game.js`：ステージ定義、固定時間刻みの物理処理、Canvas 描画

ステージ追加・調整は game.js 冒頭の levels を編集してください。spikes はトゲの位置、holes は [開始, 終了]（過去の第3要素は未使用）、ceil は [開始, 終了, 下端, 種類] です。baitHoles は閉じる穴と次の穴、spikeModes は前方移動・出直しの指定です。tunnel と temptations は狭い通路の誘導罠です。

escapeGoal は移動ゴール・即時開口・着地トゲ、underground は入口・地下床・地上の穴底・最後のトゲを定義します。10面では着地直前の入力を0.14秒受け付けます。

回帰テスト：`node scripts/test-game.cjs`

全11面の突破、ゴール接近時の失敗と再攻略、着地先行入力、地下道の入口・天井・最後のジャンプ、地上でクリアできないこと、リトライ初期化を確認します。
