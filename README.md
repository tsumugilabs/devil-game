# DEVIL GAME

自動で進む小さな悪魔をジャンプさせ、初見殺しの罠を突破する全5ステージのブラウザーゲーム。

## 遊び方

- Space / ↑ / 画面タップ：ジャンプ
- 短押し：低く跳ぶ。長押し：高く跳ぶ
- R / 「ステージをやり直す」：現在のステージから再挑戦
- クリアすると次のステージへ。死亡回数はページを開いている間の累計です。

崩れる床、低い天井、偽ゴールを配置しています。罠は固定配置で、すべてのステージに突破可能なルートがあります。

## 起動

`dist/index.html` をブラウザーで開くだけで動きます。ビルド、依存パッケージ、通信は不要です。

GitHub Pages を利用する場合は、dist の内容を公開対象に設定してください。リポジトリの公開範囲やプランによって Pages の利用可否は異なります。

## 構成

- `dist/index.html`：画面
- `dist/style.css`：レスポンシブスタイル
- `dist/game.js`：ステージ定義、固定時間刻みの物理処理、Canvas 描画

ステージ追加・調整は game.js 冒頭の levels を編集してください。spikes はトゲの位置、holes は [開始, 終了, 出現トリガー]、ceil は [開始, 終了, 下端] です。

## 検証
