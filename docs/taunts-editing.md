# 煽り文句の編集方法

編集するのは [dist/taunts.json](../dist/taunts.json) だけです。ゲームのプログラムを触る必要はありません。

## スマホ・PC共通の手順
1. SafariやChromeで [編集画面](https://github.com/tsumugilabs/devil-game/edit/main/dist/taunts.json) を開き、書き込み権限のあるGitHubアカウントでログインします。
2. 「ランダム」の文章、または「罠専用」の右側の文章を書き換えます。
3. 「Commit changes...」を押します。
4. 保存内容の説明に「煽り文句を変更」と入力します。
5. 選択肢が出た場合は「Commit directly to the main branch」を選び、「Commit changes」を押します。
6. [Actions](https://github.com/tsumugilabs/devil-game/actions) の最新の公開処理が緑のチェックになったら、[ゲーム](https://tsumugilabs.github.io/devil-game/)を再読み込みします。Actionsを手動で実行する必要はありません。

## 変更する場所
ランダムは失敗画面の大きい文章です。1行につき1件で、追加・削除できます。最低1件残してください。
罠専用はその下の文章です。左側の「通常の穴へ落下」などは用途名なので変更せず、右側だけ編集してください。

例：
```json
"通常の穴へ落下": "そこに床があると思ったんですか？",
```

## 書式のコツ
- 文章を囲む半角の `"`、区切りの `,`、括弧は残してください。
- ランダムに追加するときは既存の1行をコピーします。最後の行だけ末尾にカンマを付けません。
- 文中の引用には「」を使うと簡単です。半角の `"` を文章の中に直接入れると書式エラーになります。
- 文句は公開されます。編集権限を持つ人だけが公開版を更新できます。一般の閲覧者が変更を提案しても自動採用されません。

## 保存後に反映されない場合
Actionsの最新結果を確認します。赤い×の場合は「Validate game entrypoints」を開いてエラーを確認し、引用符・カンマ・空欄・項目名を直してもう一度保存してください。
書式チェックに失敗した更新は公開されず、それまでの公開版が残ります。
緑のチェックの場合は、少し待ってゲームを再読み込みしてください。すでに開いているゲームには自動反映されません。
